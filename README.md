# Dental RAG Assistant

Telegram-бот для відділу продажів: відповідає на питання по стоматологічних курсах на основі транскриптів лекцій.

## Як це працює

```
Питання в Telegram → ембедінг питання → пошук у ChromaDB → GPT-4o-mini → відповідь + таймкод
```

Після кожної відповіді — кнопки 👍 / 👎, оцінки зберігаються у `feedback.db`.

---

## Швидкий старт для тестування (локально)

### 1. Вимоги

- **Python 3.12** — [завантажити](https://www.python.org/downloads/)
- **uv** (менеджер пакетів) — встановити одною командою:
  ```bash
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```
- **Git**

### 2. Клонувати репозиторій

```bash
git clone https://github.com/onyevyerov/dentil_rag.git
cd dentil_rag
```

### 3. Встановити залежності

```bash
uv sync
```

Це створить `.venv/` і встановить всі пакети автоматично (~30 секунд).

### 4. Налаштувати API-ключі

Скопіювати шаблон і заповнити ключі:

```bash
cp .env.example .env
```

Відкрити `.env` і заповнити:

```env
ELEVENLABS_API_KEY=...   # потрібен тільки для транскрибації нових курсів
ANTHROPIC_API_KEY=...    # потрібен тільки для транскрибації нових курсів
OPENAI_API_KEY=...       # потрібен для роботи бота (ембедінги + GPT-4o-mini)
TELEGRAM_BOT_TOKEN=...   # токен вашого бота від @BotFather
```

> **Де взяти ключі:**
> - ElevenLabs: [elevenlabs.io](https://elevenlabs.io) → Profile → API Keys
> - Anthropic: [console.anthropic.com](https://console.anthropic.com) → API Keys
> - OpenAI: [platform.openai.com](https://platform.openai.com) → API Keys
> - Telegram: написати [@BotFather](https://t.me/BotFather) → `/newbot`

### 5. Отримати базу даних

База ChromaDB з готовими ембедінгами курсу не зберігається в репозиторії (занадто важка). Отримайте папку `chroma_db/` від основного розробника (через Google Drive, флешку тощо) і покладіть її в корінь проекту:

```
dentil_rag/
├── chroma_db/        ← сюди
├── bot.py
├── config.py
└── ...
```

> **Альтернатива:** якщо маєте доступ до аудіофайлів курсу, можна самостійно згенерувати базу (кроки нижче в розділі «Повний пайплайн»). Витрати: ~$2 на API.

### 6. Запустити бот

```bash
.venv/bin/python bot.py
```

Ви побачите:
```
INFO - ChromaDB колекція: implantology_101 (558 чанків)
INFO - Бот запущено. Натисніть Ctrl+C для зупинки.
```

Відкрийте свого бота в Telegram і напишіть `/start`. Бот готовий до роботи, поки термінал відкритий.

## Повний пайплайн (якщо потрібно обробити новий курс)

### Крок 1 — Транскрибація

Покладіть `.aac` файли курсу в папку `audio/` і запустіть:

```bash
.venv/bin/python transcribe.py --audio-dir ./audio --out-dir ./transcripts --course назва_курсу
```

Що відбувається:
- Кожен файл відправляється в **ElevenLabs Scribe v2** (українська мова)
- Транскрипт очищається через **Claude Sonnet** з глосарієм стоматологічних термінів
- Результат зберігається в `transcripts/lesson_NN.json` з таймкодами

Час обробки: ~2–3 хв на годину аудіо. Вартість: ~$0.40/год аудіо + ~$0.15/урок постобробка.

### Крок 2 — Завантаження в ChromaDB

```bash
.venv/bin/python ingest.py --transcripts-dir ./transcripts --course назва_курсу
```

Що відбувається:
- Текст розбивається на чанки по ~400 слів (LlamaIndex)
- Кожен чанк перетворюється на вектор через **OpenAI text-embedding-3-large**
- Вектори зберігаються в **ChromaDB** локально

Час: ~1 хв на курс. Вартість: менше $0.01.

### Крок 3 — Запустити бот

```bash
.venv/bin/python bot.py
```

## Структура проекту

```
dentil_rag/
├── transcribe.py     # Крок 1: аудіо → JSON транскрипти
├── ingest.py         # Крок 2: транскрипти → ChromaDB
├── bot.py            # Крок 3: Telegram RAG-бот
├── glossary.py       # Глосарій стоматологічних термінів (укр.)
├── config.py         # Налаштування (читає .env)
├── pyproject.toml    # Залежності проекту
├── uv.lock           # Зафіксовані версії пакетів
├── .env.example      # Шаблон змінних середовища
│
├── audio/            # Вхідні аудіофайли (.aac) — не в git
├── transcripts/      # JSON транскрипти — не в git
├── chroma_db/        # Векторна БД — не в git (передається окремо)
└── feedback.db       # SQLite лог оцінок — не в git
```

## Як користуватися ботом

1. Напишіть `/start` для привітання
2. Задайте будь-яке питання українською мовою
3. Бот знайде відповідні фрагменти в курсі і сформує відповідь
4. Під відповіддю — джерело (урок + таймкод) і кнопки оцінки

**Приклади питань:**
- _Яка різниця між прямокутною та трикутною формою зуба?_
- _Як правильно нарізати хайлайти?_
- _Що таке mock up і коли його використовують?_
